# promo — the Dictate videos

A Remotion project that renders the two videos for Dictate, the product promo (`src/Video.tsx`, composition `DictatePromo`) and the setup-wizard walkthrough (`src/SetupWizardVideo.tsx`). `npm install`, then `npm run dev` opens the Remotion studio and `npm run render` writes `out/dictate-promo.mp4`. Rendered output in `out/` is kept beside the source so the current cut is always to hand. Not maintained beyond that, like the app.
